# Chatbot Quick Start Guide

## What is this?

This is a fully functional NLP-based chatbot built from scratch. It can understand user intents and provide intelligent responses through natural language processing.

## How to use it?

### Quick Start (3 steps)

1. **Navigate to the chatbot directory:**
   ```bash
   cd chatbot
   ```

2. **Run the chatbot:**
   ```bash
   python3 main.py
   ```

3. **Start chatting!**
   ```
   You: Hello
   ChatBot: Hi there! What can I do for you?
   
   You: Tell me a joke
   ChatBot: Why don't programmers like nature? It has too many bugs!
   
   You: Thanks
   ChatBot: You're welcome!
   
   You: bye
   ChatBot: Goodbye! Have a great day!
   ```

## What can it do?

The chatbot can handle:
- ✅ Greetings and goodbyes
- ✅ Answer questions about itself
- ✅ Tell jokes
- ✅ Provide helpful responses
- ✅ Handle unknown inputs gracefully
- ✅ Multiple variations of the same question

## Try these commands:

```
- "Hello" / "Hi" / "Hey"
- "What's your name?"
- "Tell me a joke"
- "Can you help me?"
- "How old are you?"
- "Thank you"
- "Bye" / "Goodbye" / "quit"
```

## Customization

Want to teach the chatbot new things? Edit `intents.json` and add your own patterns and responses!
